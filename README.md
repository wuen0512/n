# Battery Tracker — Android Kotlin 原始碼

## 功能
- Android 8.0+ 前景服務監測電量、充電狀態及電池溫度；通知顯示服務運作。
- 5%、10%、20% 完整刻度區間，記錄充放電秒數與每小時電量百分比。
- 遊戲：有界數學計算與 Canvas 動畫；社交：卡片與圖片色塊捲動；影片：合成動畫影格（**不是**真實影片硬體解碼）；待機：不施加額外模擬負載。
- 測試 10/30/60/120 分鐘、42°C 電池溫度保護、每分鐘採樣、場次記錄、CSV 匯出。
- 不使用網路、無帳號、無資料上傳。

## 建置與安裝
1. 在 Windows/macOS/Linux 安裝 Android Studio（包含 Android SDK 35 和 JDK 17）。
2. 用 Android Studio **Open** 開啟 `BatteryTracker` 資料夾；等待 Gradle 同步。
3. 用 USB 連接 Android 手機，開啟開發人員選項及 USB 偵錯。
4. 按 **Run** 安裝，或 **Build > Build APK(s)** 產生 APK。
5. 開啟 App，允許通知，點選「啟動背景監測」，即可切換其他 App；需要模擬時回到 App 選擇模式、時間並開始。

## 限制與注意
- 模擬負載**只在 App 畫面可見時**運作，切換 App 或鎖屏會停止模擬，背景監測服務則繼續。部分廠商省電管理仍可能終止監測。
- 系統電量值以整數百分比回報；跳級跨越刻度時使用時間線性插值估計，並非高精度電量儀器。
- 區間計算只記錄完整、連續且對齊刻度的區間；充放電方向改變時重設未完成區間。
- 更改區間大小請在沒有進行中的模擬時操作；已在途的區間可能需要等下個完整刻度。
- 不會繞過 Android 的後台限制；不自動操控其他 App。
- 此環境缺少 Android SDK/Gradle，**未實際完成 APK 編譯或實機測試**，請先於 Android Studio 編譯驗證。
- 電量曲線以最近 200 筆採樣資料繪製，重新整理可更新。
